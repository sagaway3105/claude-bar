## 🫧 macOS 27 でも、バブルが背景に合わせて変わるようになりました

macOS 27 では、Liquid Glass が背景の明暗に合わせて自動で反転しなくなりました。そこで **ClaudeBar 自身がバブルの裏の明るさを測り、見た目をフェードで切り替える**ようにしました。追従している間は、文字を読みやすくするための幕を外すので、ガラスの透け感も増します。

- 明るさを測るために、macOS の**画面収録の許可**を使います。読むのはバブルの範囲だけで、8×8 ピクセルに縮小して平均の明るさを計算したら捨てます。**画像の保存や送信はしません**
- 許可の確認は、**バブルを初めて出すときの1回だけ**です。バブルを使わない方には表示されません。v1.6 以前でバブルを使っていた方にも、更新後に初めてバブルを出すときに1回表示されます
- 許可すると macOS から再起動を案内されます。再起動後、バブルは自動で出し直します
- 許可しなくても、バブルはこれまでどおり使えます。設定の「背景の明暗に合わせて見た目を変える」でいつでも切り替えられます
- macOS 26 以前では動きが変わらず、許可の確認も出ません

## 🪟 パネルの透け感をシステムのメニューに揃えました

macOS 26 以降のパネルを、バッテリーなどのシステムのメニューに近い Liquid Glass にしました。これまでより背景が透けて見えます。

## 📊 プランごとの違いに対応しました

Claude のプランや制限の変更に合わせました。

- **パネルの見出しにプラン名を表示します**（例: ご利用状況 Max）
- **プランに無い枠は表示しません**。5時間制限が無いプランでは、メニューバーと1つ表示は週間の使用量に切り替わり、3つ表示はその球が出なくなります
- 使用量データの新しい形式に対応しました

## 📝 表記を公式の使用量画面に合わせました

「ご利用状況」「N% 使用済み」やリセット時刻の書き方を、Claude の使用量画面に揃えました。

## 🐞 修正した不具合

**使用量の取得と表示**

- API の障害中に、Claude Code の書き込みのたびに更新を繰り返していた問題
- 中身のない応答で、正常な値が 0% に上書きされることがあった問題
- 一時的な読み取りの失敗で、誤ってログインの案内が出ることがあった問題
- 古いデータの 100% で、バブルが割れることがあった問題
- 英語環境で時刻が24時間表記になっていた問題と、初回の案内が日本語のままだった問題

**バブルの動き**

- オフラインが続いたときや、リセット時刻が空のときに、バブルが復活しなくなる問題
- すべての枠が 100% のときや枠が無いときに、見えない空のウィンドウが残る問題
- 別のディスプレイへドラッグできなかった問題
- 1つ表示と3つ表示の切り替えが破裂と重なったときの誤動作

## ⚡ CPU 使用率を下げました

カーソルがバブルから遠い間は追跡の頻度を下げ、ファイル監視や定期更新もまとめて処理するようにしました。バブル表示中のアプリ本体の CPU 使用率は、開発機の計測で**約4〜5割**下がりました（1つ表示で 1.50% → 0.92%、3つ表示で 1.83% → 0.84%）。

背景追従がオンのときは、これに加えて macOS の画面収録プロセス（`replayd`）が 1% 前後の CPU を使います。

## 🔒 セキュリティを強化しました

- Sparkle を 2.10.1 に更新しました。インストーラまわりのセキュリティ修正が含まれます
- 使用率に異常に大きい値が入っても、表示でクラッシュしないようにしました
