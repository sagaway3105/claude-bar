## 🫧 3つ表示バブルを大きくブラッシュアップしました

v1.5.1で追加した3つ表示モードを、見た目も動きも一段磨き上げました。

- **主役のセッションバブルが、1つ表示とまったく同じ大きさ・膨らみ方になりました**（基準72pt・使用量100%で1.2倍）。膨らむのは主役だけになり、小さい2球は固定サイズなので、どれが大事な数字か一目で分かります
- **3つがぎゅっと密着したひとかたまり**になり、その中で**各バブルがそれぞれ独立にふわふわ漂います**。近づいたり離れたりするたび、くびれが太くなったり細くなったり、シャボン玉らしい表情が出ます
- **虹色の縁の質感を1つ表示と統一しました**。融合ガラスの内側では虹が沈んで見えなくなるため、描画の仕組みごと見直しています
- バブル同士が繋がる部分の白い濁りを抑え、**透明感が上がりました**

## 🖱 バブルまわりのクリックが賢くなりました

- **バブルの周りの透明な領域は、背後のアプリをそのままクリックできるようになりました**。反応するのはバブルの上だけです（これまでは見えない領域がクリックを奪うことがありました）
- **バブルを画面の端まで運べるようになりました**（3つ表示も1つ表示と同じ基準）
- 3連打での破裂は**バブルごとにカウント**するようになり、別のバブルをうっかり割ってしまうことがなくなりました

## 🔍 ホバーの使用量一覧が見やすくなりました

- 一覧パネルが**バブルのすぐ横**に表示されるようになりました
- 起動直後などデータが後から届いた場合も、**パネルの幅が自動で内容に合わせて広がります**

## ⚡ CPU使用量を大幅に削減しました

- **Claude消費中のCPUが約25%→約8%に**。回転する✳ロゴの描画を全面的に作り直し、GPU側（レンダーサーバ）で回すようにしました。見た目・回転速度・脈動は従来と同じです
- **バブル非表示中のCPUはほぼゼロに**（約7%→0.2%）。隠れている間も裏でアニメーションの計算が回り続けていた問題を解消しました

## 🛠 バグ修正

たくさん直しました。主なもの:

- 3つすべて割った後、リセットが来てもバブルが復活しない
- バブルが重なった部分で、見えている球ではなく裏の球がクリックに反応する
- バブルを出し直したり画面ロックから復帰すると、球がバラバラに漂わなくなる
- 更新のインストールに失敗したとき何も表示されない
- 手動で割ったバブルが数分で勝手に復活する（正しくは「そのバブルのリセット後」）
- バブル表示中に設定で「1つ⇔3つ」を切り替えると表示が崩れる
- 破裂→復活したバブルが漂わなくなる
- 使用量の更新が止まったままになりうる穴（外部コマンドのハング対策・更新中の↻の取りこぼし・古いキャッシュによる数値の巻き戻り）
- 「ログイン時に起動」の設定が特定環境でクラッシュを起こしうる問題
- ⌘ドラッグでメニューバーのアイコンを並べ替えられない
- 外部ディスプレイの取り外しでパネルが勝手にフローティング化する／別ディスプレイからピンで戻すと位置がずれる
- フルスクリーンアプリ上でパネルを引き剥がすとメニューバーが出たままになる
- メニューバーの%表示は、使用量が高くても色が変わらないようになりました（80/95%の色替えを廃止）
