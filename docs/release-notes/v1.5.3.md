## 🔧 配布と自動アップデートを堅くするメンテナンスリリースです

**アプリの機能と見た目は v1.5.2 とまったく同じです**（アプリ本体のコードに変更はありません）。配布物と更新の仕組みだけを直しました。

- **自動アップデートの確認先を GitHub Pages に変更しました。** これまで使っていた raw.githubusercontent.com はIP単位のレート制限があり、社内ネットワークなど共有IP環境だと更新チェックが失敗し得ました。配信しているファイル自体は同じなので、v1.5.2以前をお使いの方の自動アップデートも従来どおり動きます
- **配布zipに余計なファイルが入らなくなりました。** macOSの拡張属性が `._*` という隠しファイルとして同梱されており、**`unzip` コマンドで展開した場合にだけ**アプリの署名が壊れる状態でした。Finderでのダブルクリック展開・Homebrew・アプリ内の自動アップデートは影響を受けていません。ファイルサイズも約70KB小さくなりました
