## 🔧 配布と自動アップデートを堅くするメンテナンスリリースです

**アプリの機能と見た目は v1.5.2 とまったく同じです**（アプリ本体のコードに変更はありません）。配布物と更新の仕組みだけを直しました。

- **自動アップデートの確認先を GitHub Pages に変更しました。** これまで使っていた raw.githubusercontent.com はIP単位のレート制限があり、社内ネットワークなど共有IP環境だと更新チェックが失敗し得ました。配信しているファイル自体は同じなので、v1.5.2以前をお使いの方の自動アップデートも従来どおり動きます
- **配布zipに余計なファイルが入らなくなりました。** macOSの拡張属性が `._*` という隠しファイルとして同梱されており、展開時にアプリの署名が壊れる状態でした。ファイルサイズも約70KB小さくなりました
  - **【2026-08-27 訂正】** 当初「`unzip` コマンドで展開した場合にだけ壊れ、Finderでの展開は影響を受けない」と記載しましたが、**誤りでした**。`Sparkle.framework` 内のシンボリックリンクに対応する `._*` はFinder（アーカイブユーティリティ）でも復元できず実ファイルとして残るため、**v1.3.0〜v1.5.2 はFinderでのダブルクリック展開でも署名が壊れます**（`unsealed contents present in the root directory of an embedded framework`）。Homebrew とアプリ内自動アップデートは内部で `ditto` を使うため影響ありません。該当バージョンをお使いの方は [Issue #1](https://github.com/sagaway3105/claude-bar/issues/1) の復旧手順（`find /Applications/ClaudeBar.app -name '._*' -delete` だけで直ります）をご覧ください
