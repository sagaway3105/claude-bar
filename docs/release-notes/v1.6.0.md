## 🫧 どんな背景の上でも数字が読めるバブルになりました

これまでは、白いページの上にバブルが乗ると文字が沈んで読めないことがありました。macOS 26 の Liquid Glass には「小さいガラスは背後の明るさに応じて明暗が反転し、その上の文字も一緒に反転する」という仕組みがあるので、**バブルをその仕組みに乗せました**。

- **明るい背景では文字が自動で黒く、暗い背景では白くなります。** 白いWebページの上でも、暗いエディタの上でも、そのまま読めます
- バブルの大きさを **64pt** に揃えました（3つ表示は 64 / 56 / 48pt）。この仕組みが働く境目がちょうど64ptで、これを超えると反転しなくなるためです
- 同じ理由で、**使用量に応じてバブルが膨らむ動きは廃止しました**。膨らむと途中で境目をまたいで見た目が突然変わってしまうためです
- **立体感を足しました**。縁がすっと暗くなる減光と、右下に落ちる柔らかい影で、白い背景でもバブルが「浮いている」ように見えます
- **白い背景でも虹色が見えるようになりました**。これまでの虹色は加算合成だったため、白の上では原理的に消えていました
- 使用量リングを少しだけ細くしました

## 💥 破裂が「ぐぐ...パチン」になりました

- バブルを3回クリック（または使用量100%到達）すると、**音が鳴りながらバブルがぐぐっと膨らみ**、そして**パチンと弾けます**
- 破裂の絵も作り直しました。膜が縁へ引き戻されて虹色のリングが広がり、**表面張力で分かれた滴が外へ飛び散ります**
- 破裂音は専用に合成したものを同梱しています。**設定の「バブル」タブでオフにできます**（音を切っても、膨らんで弾ける見た目はそのままです）

## 🌊 3つ表示のバブルが、それぞれ独立に漂うようになりました

3つ表示で「3つがひとかたまりで動いていて、個々に生きている感じがしない」状態でした。**描画の仕組み上、球ごとの動きが画面に反映されていなかった**ためで、構造から作り直しています。今は3つのバブルがそれぞれ違うリズムでふわふわ漂います。

## ⚙️ 設定ウィンドウを macOS 標準の形に

- **一般 / バブル / 通知 / システム の4つのタブ**に分かれました。旧来のシステム環境設定と同じ、タイトルの下にアイコンが並ぶ形です
- 選んでいるタブに合わせてウィンドウの高さが変わり、前回開いていたタブを覚えています

## 🪟 パネルの質感を macOS 標準に合わせました

メニューバーから開くパネルが、システムのコントロールセンターのパネルより明るく浮いて見えていました。Apple のガイドラインでは「ウィンドウの背景のような面には Liquid Glass ではなく標準のマテリアルを使う」とされているため、**背景をシステムのメニューと同じ素材に変更**しました。透け方がシステムのパネルとほぼ同じになっています。

## 🌐 英語表示に対応しました

パネル・バブル・設定・通知・エラーメッセージなど、**アプリ内のすべての文言が英語に対応**しました。macOS の「言語と地域」で優先する言語が日本語以外なら自動で英語になります（日本語環境ではこれまでどおり日本語です）。

## 🔧 その他の修正

- 3つ表示で、破裂の演出がバブルから最大65ptずれて表示されることがある問題を修正しました
- 古い macOS（14 / 15）では上記の自動反転が使えないため、**文字の裏にぼかした下地**を敷いて読みやすくしました
