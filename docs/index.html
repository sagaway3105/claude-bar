ClaudeBar

Claudeのプラン使用量を、macOSのメニューバーにいつも。

⬇ インストール macOS 14以降 Apple Silicon Apple公証済み 追加課金なし

機能

✳

メニューバーに常時表示

現在のセッション使用量%をいつでも確認できます。

・Claude Codeがトークンを消費している間はロゴがオレンジ色で回転します
・80% / 95% に到達すると通知センターでお知らせします

🪟

クリックで詳細パネル

クリックすると詳細パネルが開きます。

・現在のセッション / 週間制限（すべてのモデル / Fable）をリセット時刻つきで表示します
・📌でオーバーレイ（常に手前）にできます

🫧

常駐バブルモード

使用量を映すガラス玉が画面をぷかぷか浮遊します。3つ表示にすると、セッション・Fable・週間がシャボン玉の塊になってそれぞれ漂い、マウスを載せると一覧が出ます。

・3回クリックすると弾けます
・使用量が100%になると弾けます

その他の機能

  • 自動アップデート — 新バージョンをワンクリックで（Sparkle）
  • 通知 — 80% / 95%到達時に通知センターへ
  • バブルの表示切替 — 1つ（表示メトリクス選択）／3つ同時表示を設定で切替
  • 追加利用の表示 — extra usage有効時は消費額も表示
  • ログイン時に自動起動 — 設定からワンクリックで登録
  • 更新間隔 — 1・2・5分から選択

しくみ

Claude Codeのログインをそのまま利用します。アプリ自体にログイン画面はなく、公式CLIの認証情報を読み取り専用で参照して、使用量照会APIをポーリングするだけ。パスワードがアプリを経由することはなく、トークン消費や追加課金も発生しません（Pro / Maxプラン対応）。

インストール

条件: Apple SiliconのMac（M1以降） ・ macOS 14以降 ・ Claude Pro / Maxプラン

  1. アプリを入れる — 2パターンどちらでもOK: Homebrew brew install --cask sagaway3105/tap/claudebar 手動 ⬇ 最新版をダウンロード
    zipを解凍して ClaudeBar.app をアプリケーションフォルダへ
  2. 起動するとメニューバーに「–% ✳」が出ます（Apple公証済み・警告なしで起動）
  3. 初回はパネルの案内に従ってClaude Codeでログイン連携（未導入でも2ステップの案内つき）

初回にmacOSのアクセス許可の確認が表示されたら「許可」を選択してください。
