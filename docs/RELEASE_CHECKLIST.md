# リリース前チェック

`scripts/preflight.sh <バージョン>` が自動の検査を行い、最後に下の手動項目の確認を求めます。
通過の記録が無いコミットは `scripts/release.sh` が配布を止めます。

過去の不具合を再発させないためのものです。不具合を直したら、自動で検査できるものはテストや
スクリプトへ、できないものはこの一覧へ追加してください。

## 自動（preflight.sh）

- 作業ツリーがコミット済みで、バージョンが既存のタグより新しい
- リリースノートがあり、下書きの印が残っていない
- テストが通常時と旧OS分岐の強制時（`CLAUDEBAR_FORCE_LEGACY=1`）の両方で通り、0件で素通りしていない
- `.app` を組み立てられ、SDK とリソースの検証（Issue #2）と署名の検証に通る
- 配布 zip に `._*` が混入せず、展開後も署名が有効（Issue #1）
- このコミットの CI が成功している（macOS 26 でのテストと、macOS 15 のランナーでの起動確認。macOS 14 のランナーは廃止された）

## 手動

### レビュー

- [ ] 前回のタグ以降の全差分をコードレビューし（Claude Code なら `/code-review high`）、指摘を確認して対応した
- [ ] リリースノートを前回のタグ以降の `git log` と突き合わせた。未確認のことを確認済みのように書いていない

### 許可の流れ（macOS 27）

`tccutil reset ScreenCapture com.atsushisagae.ClaudeBar` と
`defaults delete com.atsushisagae.ClaudeBar followBackgroundOffered` で初回の状態に戻して確認する。

- [ ] バブルを初めて出すと許可のダイアログが1回だけ出て、2回目以降は出ない
- [ ] 許可して再起動すると、バブルが自動で出て背景に追従する
- [ ] 断っても幕つきで動き、ダイアログを繰り返さない

### バブル

- [ ] 明るい背景と暗い背景の上で、外観がフェードで切り替わり、文字が読める（1つ表示と3つ表示）
- [ ] 別のディスプレイへドラッグでき、そのディスプレイを外すとバブルが画面内へ戻る（複数ディスプレイの環境で）
- [ ] 1つ表示と3つ表示の切り替えを繰り返しても、窓のサイズや当たり判定が崩れない
- [ ] 手動で割ると復活を予約し、割れた球が次の更新で勝手に戻らない
- [ ] 見えない空の窓が残らない（割ったあとに、バブルがあった場所をクリックできる）

### 使用量の取得

- [ ] ネットワークを切ると、古い値に更新時刻の表示が出て、`claude` が連続で起動しない（`pgrep -fl 'claude -p'` で確認）
- [ ] つなぎ直すと、自動で最新の値に戻る
- [ ] パネルの見出しのプラン名と使用量が公式の使用量画面と一致する

### 言語と旧OS

- [ ] 英語環境（`defaults write com.atsushisagae.ClaudeBar AppleLanguages '("en")'`、確認後に `defaults delete` で戻す）で、初回案内と時刻表記が英語になっている
- [ ] `CLAUDEBAR_FORCE_LEGACY=1` で起動して、パネルとバブルが崩れない

### 更新

- [ ] 公開後、1つ前のバージョンから自動アップデートして起動できる（Issue #1, #2）
